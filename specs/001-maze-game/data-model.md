# Data Model: Maze Game

**Date**: 2025-12-08
**Feature**: Maze Game (001-maze-game)
**Purpose**: Define core data structures and entities for game state

## Overview

This document defines all data structures, entities, and their relationships for the Maze Game implementation. All entities are JavaScript objects (no classes required, though classes may be used for encapsulation).

---

## 1. Maze Entity

Represents the generated maze grid with walls, paths, start, and exit positions.

### Structure

```javascript
{
  width: number,           // Grid width (15, 25, or 40 based on difficulty)
  height: number,          // Grid height (15, 25, or 40 based on difficulty)
  grid: number[][],        // 2D array: 0 = path, 1 = wall
  start: { x: number, y: number },  // Starting position (usually 0, 0)
  exit: { x: number, y: number },   // Exit position (usually width-1, height-1)
  difficulty: string       // 'easy' | 'medium' | 'hard'
}
```

### Example

```javascript
const maze = {
  width: 25,
  height: 25,
  grid: [
    [0, 1, 0, 0, 1, ...], // Row 0
    [0, 0, 0, 1, 0, ...], // Row 1
    // ... 25 rows total
  ],
  start: { x: 0, y: 0 },
  exit: { x: 24, y: 24 },
  difficulty: 'medium'
};
```

### Validation Rules

- `width` and `height` must match difficulty: Easy (15), Medium (25), Hard (40)
- `grid` must be `height` rows × `width` columns
- `grid[y][x]` values must be 0 (path) or 1 (wall)
- `start` and `exit` positions must be within grid bounds
- `start` and `exit` must be on path cells (grid value = 0)
- Maze must have at least one valid path from start to exit (enforced by generation algorithm)

### State Transitions

- **Created**: Maze generated by `MazeGenerator.generate()`
- **Active**: Currently being navigated by player
- **Completed**: Player reached exit position

## 2. Player Entity

Represents the mouse/rat character state, position, and animation.

### Structure

```javascript
{
  x: number,               // Current grid X position (0 to maze.width-1)
  y: number,               // Current grid Y position (0 to maze.height-1)
  direction: string,       // 'up' | 'down' | 'left' | 'right' | null
  animationState: string,  // 'idle' | 'walking' | 'collision'
  lastMoveTime: number,    // Timestamp of last movement (for auto-repeat)
  spriteFrame: number      // Current animation frame index
}
```

### Example

```javascript
const player = {
  x: 5,
  y: 3,
  direction: 'right',
  animationState: 'walking',
  lastMoveTime: 1234567890,
  spriteFrame: 2
};
```

### Validation Rules

- `x` must be in range [0, maze.width-1]
- `y` must be in range [0, maze.height-1]
- Player position (x, y) must always be on a path cell (maze.grid[y][x] === 0)
- `direction` is null when idle, otherwise one of 4 cardinal directions
- `animationState` determines which sprite frames to use
- `spriteFrame` cycles through available frames for current animation

### State Transitions

1. **Idle** → **Walking**: Player presses arrow key
2. **Walking** → **Idle**: Player stops pressing keys (or releases key)
3. **Walking** → **Collision**: Player attempts move into wall
4. **Collision** → **Idle**: Collision animation completes (~200ms)

## 3. Timer Entity

Tracks elapsed gameplay time from start to victory/reset.

### Structure

```javascript
{
  startTime: number | null,  // Timestamp when timer started (null if not started)
  pausedTime: number,        // Accumulated paused time (milliseconds)
  isRunning: boolean         // Whether timer is currently counting
}
```

### Example

```javascript
const timer = {
  startTime: 1702051200000,  // Unix timestamp
  pausedTime: 0,
  isRunning: true
};
```

### Derived Values

```javascript
// Calculated, not stored
function getElapsedSeconds(timer) {
  if (!timer.startTime) return 0;
  const now = Date.now();
  const elapsed = now - timer.startTime - timer.pausedTime;
  return Math.floor(elapsed / 1000);
}

function formatTime(timer) {
  const seconds = getElapsedSeconds(timer);
  const mins = Math.floor(seconds / 60);
  const secs = seconds % 60;
  return `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`;
}
```

### State Transitions

1. **Not Started** (startTime = null) → **Running**: Game starts
2. **Running** → **Stopped**: Player reaches exit
3. **Running** → **Reset**: Player changes difficulty
4. **Stopped** → **Reset**: Player starts new game

## 4. AudioSettings Entity

Manages audio playback state and volume controls.

### Structure

```javascript
{
  masterVolume: number,      // 0.0 to 1.0 (0% to 100%)
  isMuted: boolean,          // True if audio is muted
  previousVolume: number,    // Volume level before muting (for restore)
  context: AudioContext | null,  // Web Audio API context
  sounds: Map<string, AudioBuffer>,  // Loaded sound buffers
  sources: Map<string, AudioBufferSourceNode>  // Active sound sources
}
```

### Example

```javascript
const audioSettings = {
  masterVolume: 0.7,
  isMuted: false,
  previousVolume: 0.7,
  context: new AudioContext(),
  sounds: new Map([
    ['background-music', audioBuffer1],
    ['move-sound', audioBuffer2],
    ['wall-hit', audioBuffer3]
  ]),
  sources: new Map([
    ['background-music', sourceNode1]
  ])
};
```

### Validation Rules

- `masterVolume` must be in range [0.0, 1.0]
- When `isMuted` is true, actual playback volume is 0 (but `masterVolume` is preserved)
- `previousVolume` stores `masterVolume` before muting for restore
- `context` must be initialized before loading sounds
- Sound keys: 'background-music', 'move-sound', 'wall-hit'

### State Transitions

1. **Unmuted** → **Muted**: User toggles mute button
2. **Muted** → **Unmuted**: User toggles mute button (restores `previousVolume`)
3. **Any** → **Volume Changed**: User adjusts volume slider

## 5. GameState Entity

Central state object containing all game data.

### Structure

```javascript
{
  maze: Maze | null,
  player: Player | null,
  timer: Timer,
  difficulty: string,        // 'easy' | 'medium' | 'hard'
  audioSettings: AudioSettings,
  isVictory: boolean,
  observers: Function[]      // Observer callbacks for state changes
}
```

### Example

```javascript
const gameState = {
  maze: { /* Maze object */ },
  player: { /* Player object */ },
  timer: { /* Timer object */ },
  difficulty: 'medium',
  audioSettings: { /* AudioSettings object */ },
  isVictory: false,
  observers: [uiUpdateCallback, audioEventCallback]
};
```

### Methods

```javascript
// Initialize new game
function initGame(state, difficulty) {
  state.difficulty = difficulty;
  state.maze = MazeGenerator.generate(getDimensions(difficulty));
  state.player = createPlayer(state.maze.start);
  state.timer = createTimer();
  state.isVictory = false;
  state.timer.isRunning = true;
  notifyObservers(state, 'gameInitialized', { difficulty });
}

// Reset game (same difficulty)
function resetGame(state) {
  initGame(state, state.difficulty);
  notifyObservers(state, 'gameReset');
}

// Change difficulty (triggers reset)
function setDifficulty(state, newDifficulty) {
  state.difficulty = newDifficulty;
  initGame(state, newDifficulty);
  notifyObservers(state, 'difficultyChanged', { difficulty: newDifficulty });
}

// Check for victory condition
function checkVictory(state) {
  if (state.player.x === state.maze.exit.x &&
      state.player.y === state.maze.exit.y) {
    state.isVictory = true;
    state.timer.isRunning = false;
    const time = formatTime(state.timer);
    notifyObservers(state, 'victory', { time });
    return true;
  }
  return false;
}
```

### State Transitions

1. **Uninitialized** → **Playing**: `initGame()` called
2. **Playing** → **Victory**: Player reaches exit
3. **Playing** → **Playing** (reset): Difficulty changed or manual reset
4. **Victory** → **Playing**: New game started

## 6. Input State

Tracks keyboard input state for movement and auto-repeat.

### Structure

```javascript
{
  keysPressed: Set<string>,     // Currently held keys (e.g., 'ArrowUp')
  lastKeyTime: Map<string, number>,  // Timestamp of last key press for auto-repeat
  autoRepeatDelay: number       // 500ms (0.5 seconds) per spec
}
```

### Example

```javascript
const inputState = {
  keysPressed: new Set(['ArrowRight']),
  lastKeyTime: new Map([
    ['ArrowRight', 1702051200500]
  ]),
  autoRepeatDelay: 500
};
```

### Validation Rules

- Only arrow keys tracked: 'Arrow Up', 'ArrowDown', 'ArrowLeft', 'ArrowRight'
- Auto-repeat triggers only after `autoRepeatDelay` milliseconds
- Key must remain continuously pressed for auto-repeat
- Only one movement processed per frame (prioritize most recent key)

## Data Relationships

```text
GameState (1)
  ├── contains (1) Maze
  ├── contains (1) Player
  │     └── positioned in → Maze.grid[y][x]
  ├── contains (1) Timer
  ├── contains (1) AudioSettings
  └── manages (n) Observers (callbacks)

Player
  └── victory condition → (player.x === maze.exit.x && player.y === maze.exit.y)

Timer
  └── stops when → GameState.isVictory === true

InputState (separate from GameState)
  └── triggers → Player movement
```

## Persistence

**Note**: Per spec, no game state persistence is required. All data exists in memory only and is lost on page refresh.

If future persistence is needed:
- Store `difficulty` and `audioSettings.masterVolume` in `localStorage`
- Do NOT persist maze or player state (new game on each load)

---

## Summary

| Entity | Purpose | Lifetime |
|--------|---------|----------|
| **Maze** | Grid structure with walls/paths | Created on game start, recreated on difficulty change |
| **Player** | Character position and animation | Exists while game is active, reset on difficulty change |
| **Timer** | Track elapsed time | Starts with game, stops on victory/reset |
| **AudioSettings** | Volume and mute state | Persists across games (but not page refreshes) |
| **GameState** | Root container for all entities | Exists for entire session |
| **InputState** | Keyboard tracking | Exists for entire session |

All entities follow immutable update patterns where possible (create new objects rather than mutating), though JavaScript objects are inherently mutable.
